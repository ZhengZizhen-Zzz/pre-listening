# Security

Do not publish API keys, trial credentials, private recordings, presentation files or user feedback in issues, commits or screenshots. Reproduce problems with synthetic materials.

This repository is a local / invited-trial application, not a hardened public multitenant service. See [data handling and deployment boundaries](docs/DATA.md). Keep dependencies current and use authentication, HTTPS and a controlled file-conversion environment before sharing externally.

For a sensitive report, use an available private channel with the repository owner. Do not post exploit details containing user data in public issues.
