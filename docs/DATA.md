# 数据路径与公开范围

## 仓库包含什么

公开代码、设计文档、自动化测试、合成评估输入，以及虚构案例的产品截图。另提供一例真实反馈的人工去标识摘要和一组以合成材料执行的真实模型决策记录；后者包含结构化动作与工具观察，不包含内部推理或凭证。

没有上传开发者 `.env`、模型密钥、试用密码、真实录音、真实 PPT、用户反馈原文、联系人信息或私人服务运行日志。公开导出没有继承私人开发目录的 Git 历史。真实案例与合成演示分别标记，详情见[用户案例](USER-CASE.md)与[决策记录](AGENT-TRACE.md)。

## 运行时数据去哪了

| 内容 | 处理路径 |
| --- | --- |
| 演练历史、讲稿、录音 | 主要保存在当前站点的浏览器 IndexedDB；换设备不会自动同步 |
| PPT 转换 | 材料按需传到你运行的服务，调用 LibreOffice 转换，任务文件在服务端暂存 |
| 图片文字识别 | 页面图片可发送至你运行的服务；macOS Vision 在服务端本地识别 |
| 自动转写 | 音频和辅助术语发送至百炼；语音供应商按其服务规则处理 |
| 分析、改稿、问答、Agent | 相关材料文字、发言与目标发送给配置的文本模型服务 |
| 主动反馈 | 使用感受及可用的文字复盘提交到你的服务；不随反馈提交原始录音和文件 |

“主要本地保存”不代表永不联网。使用 AI 功能前应确保有权处理相应材料。

## 试用部署的边界

`TrialAccess` 使用邀请密码哈希、签名会话 Cookie、Origin / CSRF 检查与工作流额度；公开试用不能访问反馈管理端。反馈管理仅供本地维护者查看，不是公开社区内容。密码保存在服务端配置中，不应进入前端或 GitHub。

当前额度按工作流计数，不等于原始模型请求数或费用。模型服务费用仍由配置密钥的账户承担。

单进程任务、浏览器存储和受邀试用的设计不能代替正式运营的身份系统、审计、备份和数据删除流程。上线前应另外评估访问控制、文件解析隔离、配额、依赖更新与数据保留。
